# Processed research data

This directory contains processed research files retained for traceability and reproducibility of the manuscript analyses.

```text
data/
├── breast_cancer/   # final fixed breast-cancer GCC + query provenance
├── corum/           # final fixed CORUM-derived GCC benchmark input
└── yeast/           # processed STRING networks, COBS searches, benchmark outputs
```

Raw third-party source exports are intentionally not redistributed here when they are unnecessary for reproduction or when redistribution conditions are restrictive or unclear. Source locations and provenance are documented in [`../docs/DATA_SOURCES.md`](../docs/DATA_SOURCES.md).

For manuscript-to-file mapping, see [`../docs/PUBLICATION_DATA_MAP.md`](../docs/PUBLICATION_DATA_MAP.md).
